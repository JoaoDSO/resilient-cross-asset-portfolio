# Data Note

The public GitHub version does not include the full raw and cached development data.

The final HTML report and executed notebook contain the analysis outputs used for review. The `outputs/` folder includes the final portfolio-weight CSV files, and the `figures/` folder includes selected generated figures.

The original project used a 104-asset universe with market, fundamental and macro-governance inputs. Results should be interpreted as a static academic-project snapshot because live financial data and provider access can change.
